Quick Guide

Two lightweight tools built around a stack of sliced scan images — no server, no login, just files.

Educator annotates in Annotator → Exports annotations.json → Student opens Quiz

E For educators — Annotator

annotator/index.html

  1. Scrub through the slices Use the slider (or Play) below the image to move through the stack.
  2. Add an annotation Drag a type from the left palette onto the spot on the slice — or on touch, tap the type, then tap the slice. Fill in its content in the panel on the right.
  3. Set its acceptable range A radius slider is the quick default; "Draw shape" lets you trace a custom region instead — this is how close a student's guess needs to be to count as correct.
  4. Browse and fix things up "On this slice" and the expandable "All annotations" list (sortable) jump you straight to any item. Drag a marker to reposition it.
  5. Export Choose Quiz (students place things themselves) or Showcase (read-only walkthrough) — and for a quiz, Full challenge (find the slice too) or Guided (slice is hinted). Downloads annotations.json.

Annotation types

  • Text label — short text shown right on the image
  • Pin + description — marker with a longer write-up
  • MCQ — marker with a multiple-choice question
Work autosaves to the browser as you go. Import… loads a previous export back in for further editing.

S For students — Quiz

quiz/index.html

If it's a Showcase: click any item in the list — it jumps to the right slice and shows its full content. Nothing to do but read.

If it's a Quiz:

  1. Pick an item to place Tap it in the "To place" list (it "arms"), then tap the slice where you think it belongs — or drag it onto the stage. In guided quizzes, a small dot on the slider hints the right slice.
  2. Answer MCQs directly MCQs are already placed for you — click one in the list to jump straight to it, then choose an answer from the dropdown.
  3. Adjust anytime Drag a placed marker to reposition it, or reopen it from the list to review or clear it.
  4. Check your answers Grades everything at once and reveals the true location/content for anything you attempted.
  5. Try again Clears every attempt so you can have another go.

Status icons (quiz list)

  • Not placed/answered yet
  • Attempted, not yet checked
  • Correct
  • Incorrect
Import… loads a different annotations.json if you have one — otherwise the quiz uses whatever file is bundled next to the page.

Using your own images

Swap out the sample apple-slice dataset for a real one

Drop .svg, .png, .jpg/.jpeg, .gif or .webp images into data/slices/ (names can have spaces), then run python3 scripts/build_manifest.py to rebuild the slice list — files sort naturally by name, so abc2.jpg comes before abc10.jpg whether or not you zero-pad. See the README for the full technical reference, including the annotations.json schema.

Pure HTML/CSS/JS, no server-side storage — everything here is just files in this folder.
